# Model A (C4H8) Production Release v1

This folder contains all the frozen, validated components for the Model A soft-sensor.

## Folder Structure
*   `models/` — Frozen model binaries (.json, .pkl) and diagnostic validation plots.
*   `configs/` — Production feature configuration JSON.
*   `reports/` — Feature importance CSV and final summary report.
*   `inference/` — Live DCS prediction script with fallback logic.
*   `notebooks/` — Formal leak-free target validation script.
